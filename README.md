# Retail Sales & Profitability Analytics

## Project Overview
This project analyzes retail sales data to understand sales performance, profitability, regional trends, and monthly business performance using Google Sheets, SQL, and Power BI.

## Tools Used
- **Google Sheets:** Data cleaning, validation, and exploratory analysis
- **SQL:** Data querying, aggregation, and business analysis
- **Power BI:** Interactive dashboard and data visualization
- **GitHub:** Project documentation and version control

## Dataset
- **Records:** 12,000
- **Period:** January–June 2026
- **Data type:** Retail sales transactions

## Data Cleaning
- Removed duplicate records
- Checked missing values
- Handled missing city and payment-mode values
- Reviewed data consistency and formatting
- Checked numerical values for potential outliers

## Key Analysis
- Total sales and total profit
- Region-wise sales performance
- Region-wise profitability
- Category-wise sales and profit
- Monthly sales and profit trends
- Top-performing products

## Key Findings
- **Total Sales:** Approximately ₹297.37 million
- **Total Profit:** Approximately ₹54.07 million
- **Top Sales Region:** South
- **Highest-Profit Category:** Electronics
- **Highest-Sales Month:** May 2026

## Dashboard
The Power BI report includes KPI cards for total sales, total profit, and record count, along with a region-wise sales bar chart and a monthly sales and profit trend chart.

## Project Objective
To transform raw retail transaction data into meaningful business insights that support sales monitoring, profitability analysis, and data-driven decision-making.

## Project Status
Personal portfolio project completed using a sample retail dataset.
